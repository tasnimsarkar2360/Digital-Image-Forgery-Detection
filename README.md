# Digital-Image-Forgery-Detection
MATLAB system for detecting digital image forgery with DSP. It extracts 29 RGB features (ELA, block-DCT/Benford, FFT, wavelet noise, Laplacian, CFA, JPEG blockiness), classifies with Logistic Regression, SVM and Random Forest, and localizes forged regions with a DSP heatmap and a block-DCT copy-move detector.
